# Architecto — Documentation

**Architecto** est un agent IA « Software Architect » qui assiste la conception
logicielle (analyse de besoins, choix d'architecture, ADR, diagrammes, revue de code)
en s'appuyant sur une base de connaissances vectorielle.

La documentation est disponible en deux langues / Documentation is available in two languages:

- 🇫🇷 **Français** → [`fr/`](fr/README.md)
- 🇬🇧 **English** → [`en/`](en/README.md)
