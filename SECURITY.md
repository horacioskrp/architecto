> 🇫🇷 Français ci-dessous · 🇬🇧 English below

## 🇫🇷 Français

### Versions prises en charge

Le projet est en développement actif (pré-1.0). Les correctifs de sécurité
ciblent la **dernière version de la branche `main`**. Les versions antérieures ne
sont pas maintenues.

| Version | Prise en charge |
|---------|-----------------|
| `main` (dernier) | ✅ |
| Antérieures | ❌ |

### Signaler une vulnérabilité

**Merci de ne pas ouvrir d'issue publique pour une faille de sécurité.**

Utilise de préférence le canal **privé** de GitHub :

1. Onglet **Security** du dépôt → **Report a vulnerability** (GitHub Private
   Vulnerability Reporting).

À défaut, écris à **horaciodigijob@gmail.com** avec l'objet `[SECURITY]`.

Merci d'inclure, si possible :

- une description de la vulnérabilité et de son impact ;
- les étapes de reproduction (ou un PoC) ;
- les versions / composants concernés (backend, frontend, SDK).

### Ce à quoi t'attendre

- **Accusé de réception** sous ~72 h.
- Une évaluation et, le cas échéant, un correctif coordonné.
- Une divulgation publique **après** la mise à disposition d'un correctif.

Nous te demandons de laisser un délai raisonnable pour corriger avant toute
divulgation publique. Merci pour ta divulgation responsable.

## 🇬🇧 English

### Supported versions

The project is under active development (pre-1.0). Security fixes target the
**latest `main` branch**. Older versions are not maintained.

| Version | Supported |
|---------|-----------|
| `main` (latest) | ✅ |
| Older | ❌ |

### Reporting a vulnerability

**Please do not open a public issue for a security vulnerability.**

Prefer GitHub's **private** channel:

1. Repository **Security** tab → **Report a vulnerability** (GitHub Private
   Vulnerability Reporting).

Otherwise, email **horaciodigijob@gmail.com** with subject `[SECURITY]`.

Please include, if possible:

- a description of the vulnerability and its impact;
- reproduction steps (or a PoC);
- affected versions / components (backend, frontend, SDK).

### What to expect

- **Acknowledgement** within ~72 hours.
- Triage and, where warranted, a coordinated fix.
- Public disclosure **after** a fix is available.

We ask that you allow reasonable time to remediate before any public
disclosure. Thank you for practising responsible disclosure.
